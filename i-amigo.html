I.Amigo — Sua I.A Amiga!

I.Amigo Groq Online • Llama 3.3

Sua I.A Amiga!

Sou I.Amigo, sua I.A Amiga :). Vamos conversar sobre o que hoje?!

Enter envia · Shift+Enter quebra linha

01 • Como a I.Amigo funciona

Conversa natural ao vivo com proxy seguro na borda

Projetada para soar acolhedora desde o primeiro "oi", mantendo zero segredos no navegador e continuidade mesmo sob limite de requisições.

01 / PERSONALIDADE & TOM

Personalidade antes de vendas

Acolhedora, leve e curiosa para falar de café, música, rotina ou código sem empurrar orçamento. Só menciona o estúdio com link discreto para contato se o visitante trouxer um projeto digital.

02 / EDGE PROXY & CORS

Cloudflare Worker Proxy

As mensagens vão direto para o Worker em produção com validação de origem (CORS) e limite de histórico. A chave da API permanece protegida nos Secrets da Cloudflare, nunca exposta no navegador.

03 / INFERÊNCIA & FALLBACK

Groq Llama 3.3 70B Free Tier

Inferência ultrarrápida com llama-3.3-70b-versatile via API da Groq. Se a cota gratuita (429) ou a rede oscilar, o chat alterna automaticamente para o Modo Amigo Local sem interromper o papo.

Ver código-fonte no GitHub (dedss22/i-amigo) ↗
